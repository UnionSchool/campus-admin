# Campus Admin

面向智慧校园后台管理场景的 Vue 3 前端框架。

- npm：`@unionschool/campus-admin`
- 演示与文档：<https://campus.zhongxiaotong.com>
- 源码：<https://github.com/UnionSchool/campus-admin>

> 当前处于早期开发阶段，API 可能调整，暂不建议直接用于生产环境。

## 本地开发

要求 Node.js 20.19 或更高版本。

```bash
npm ci
npm run dev
```

发布前检查：

```bash
npm run check
```
